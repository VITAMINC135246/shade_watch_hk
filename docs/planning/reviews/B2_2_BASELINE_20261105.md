## Method

- Per-entry listing with Python `os.scandir` (no symlink following): relative path, type, size, `st_mtime_ns`, mode, symlink target. Same basis as the B2.0 baseline (size + mtime; no content hashes for the data trees).
- Entries are grouped into **units**: the smallest folder in which a new child is a permitted new entry under `SW-B2.2` ("Write scope and allowed files").
  - `data/raw`: depth 4 (`data/raw/<x>/<y>`).
  - `data/processed`: depth 4 under `shade_v1/` and `dsm_views/` (one unit per namespace or view folder), depth 3 elsewhere.
  - `outputs`: depth 3 under `shade_map_work/` (one per `<name>-<id12>/`), depth 4 under `shade_map_work/.locks/` (one per lock file), depth 3 under `region_views/` (one per key), depth 2 elsewhere.
  - `presentations`: depth 2.
  - Shallower directories are **containers** (they may gain new units).
- Unit digest: SHA-256 of the sorted lines `rel\td` (directory, no mtime), `rel\tf\tsize\tmtime_ns` (file), `rel\tl\ttarget\tmtime_ns` (symlink). Directory mtimes are kept in the full listing for investigation.
- Coastline: mode of every entry and SHA-256 of every file. Planner files: SHA-256 of every untracked non-ignored file (excluding `docs/sea2/evidence/b2_2/`) plus `.gitignore`.

1. Re-run the listing script (below) on the same trees.
2. Every baseline unit must be present with the same digest. A changed digest in a pre-existing unit is a write-scope finding: list its files with `mtime > baseline` and compare counts to name additions, changes and deletions.
3. Every new unit must lie in an allowed location: `data/processed/dsm_views/sea_fill_v2_2/`; `data/processed/shade_v1/{sea_fill_v2_2_*, sea2_2_fill_impact_*, sea2_2_raw_*}`; `outputs/sea2_2_*`; new `outputs/shade_map_work/<name>-<id12>/` and `.locks/<name>.lock` for new run names; new `outputs/region_views/<key>/`.
4. Coastline: identical SHA-256 and identical modes (all 4 dirs `700`, all 423 files `600`) after the developer's blackout and restore.
5. Planner files: identical SHA-256.

Known noise: `.DS_Store` files change when Finder opens a folder; WK4 presentation work that the user gives to Codex separately could change `presentations/shade_watch_wk4_*`. Either must be attributed, not silently excused.

def depth_for(p):
    if p[0] == 'data' and p[1] == 'raw': return 4
    if p[0] == 'data' and p[1] == 'processed':
        return 4 if len(p) > 2 and p[2] in ('shade_v1', 'dsm_views') else 3
    if p[0] == 'outputs':

        if len(p) > 1 and p[1] == 'region_views': return 3
